The Journey

280 commits later.

Every line earned through real problems, real debugging, real pivots.

It started with 3 shell scripts

An Alpine Linux profile, an overlay generator, and a build script. No Yocto. No BitBake. No 6-hour build times. The goal was simple: a full Wayland desktop that builds in minutes, not hours.

The installer went through 3 lives

First it was written in Go. Then Calamares — which turned out to be removed from Alpine repos after v3.19. Finally landed on Python + tofi GUI. Each rewrite taught something the previous one couldn't.

Chrome on musl was a war

Running Google Chrome on pure Alpine musl meant building an entire glibc isolation layer. 63 packages from Debian Bookworm. A custom zapt package manager that handles .deb extraction with dependency resolution. Per-binary ldd checks. A library sandbox at /usr/lib/glibc/. It took dozens of commits to get right.

RAM was always the enemy

Live USB booted into tmpfs — Chrome ate all the RAM. Built a flash-overlay service that auto-creates an ext4 partition on first boot. The OS now uses USB storage instead of RAM for the writable layer. Desktop stays responsive even with 2GB RAM.

The desktop kept evolving

WhiteSur-Light became Catppuccin Mocha. One waybar became three. Thunar became Double Commander (via zapt from Debian pool). rofi was replaced with tofi. Every component was questioned, tested, and replaced if something better existed.

Still building.

IPv6 support. TCP BBR. Offline USB installer with prebuilt bootloader. Every commit solves a real problem encountered during actual use. This isn't a weekend project — it's a production system under active development.

What You Get

Real desktop. Tiny footprint.

Not a minimal install. A complete, configured, ready-to-use system.

5-Minute Build

Docker or native Alpine. One command. Compare that to Yocto's 2-6 hour builds with 50GB disk usage.

Wayland Native

LabWC compositor — OpenBox-style window management for Wayland. No X11, no XWayland dependency.

~300MB ISO

Full desktop with browser, file manager, terminal, notifications. USB boot, Rufus, Ventoy compatible.

Chrome on Musl

Google Chrome runs on pure Alpine musl via a custom glibc isolation layer. 63 Debian libraries sandboxed at /usr/lib/glibc/.

Catppuccin Mocha

Unified dark theme across labwc, waybar, mako, tofi, GTK. Three-panel layout with workspaces, system info, and controls.

USB Overlay

Auto-creates ext4 partition on first boot. Overlayfs uses USB storage instead of RAM — desktop stays fast on low-memory machines.

zapt Package Manager

Custom .deb installer with dependency resolution for Alpine musl. Downloads from Debian pool, isolates glibc libraries, checks apk ownership conflicts.

Offline Installer

Python + tofi GUI. Copies live USB via tar pipe. Prebuilt bootloader with GRUB fallback. sfdisk partitioning with GPT. No network needed.

Quick Start

Build your own.

Docker recommended. Works on any Linux with Docker installed.

Docker Build

Recommended
Terminal 
git clone https://github.com/kelvinzer0/superlite-os.git
cd superlite-os
./build.sh --docker

Native Alpine

Alpine Linux 
# On an Alpine system:
./build.sh

# Or set up environment only:
./build.sh --setup-only
cd /root/aports/scripts
./mkimage.sh --profile superlite \
  --arch x86_64 --outdir ~/iso/ --tag latest

Test in QEMU

QEMU 
# Simple mode (serial console)
./run-qemu-simple.sh

# Full mode with GUI
./run-qemu.sh --memory 2G --gui

# Debug mode with tmux
./run-qemu-debug.sh
